このプロジェクトが「何をするか」を書く文書です。「どう作るか」は [DESIGN.md](DESIGN.md) に書きます。


## 1. 目的と範囲

- 目的:スマホのブラウザで動く、釣り×クリッカー(放置でも進むゲーム)×ローグライク/ハクスラ(ランごとに変わる装備で強くなるゲーム)のゲームを作る(D-016)。
- 目標の姿:「自動で釣れる気持ちよさと、強い魚とのミニゲーム、ランごとに変わる装備の組み合わせで強くなっていく釣りゲーム」。迷ったときは、これに近づくほうを選ぶ(D-017)。
- 進み方:普通の魚は自動で釣れ続ける。強い魚が掛かったらミニゲーム。強い魚ほど重いミニゲームにする(D-018)。
- ランの終わり方:1 ランは数分の時間制。時間が尽きたら終わり、持ち帰った素材で強化する(D-019)。
- 作る順番:①釣りの 1 サイクル → ②釣ったものと素材 → ③強化 → ④ローグライク・ハクスラ要素(D-023)。
- 今あるもの:①釣りの 1 サイクル(この文書の 5 章)。
- まだないもの:素材、強化、ショップ、時間制のラン、ローグライク・ハクスラ要素、セーブ(保存)、音、2 つ目以降のミニゲーム、複数の釣り場。

## 2. 使う人と使い方

- 縦持ちのスマホで、ブラウザから遊ぶ(D-020)。
- 操作はタップだけ。放置していても、普通の魚は釣れ続ける。

## 3. 入力

- タップ(画面のどこでも)。ミニゲームの間だけ意味がある。
- URL の `?seed=数` で、乱数のシードを固定できる(D-021・D-030)。付けないときは毎回ちがうシードになり、画面の左下に表示される。

## 4. 出力

- 画面の上:釣れた数(普通の魚/強い魚)と、逃げられた数。
- 画面の中ほど:今の場面の文(「待っています…」「掛かった!」「強い魚だ!」、結果)。
- 絵:空・水面・竿・糸・浮き・魚、ミニゲームのゲージ。画像素材は使わず、図形で描く。

## 5. 計算の中身

### 5.1 釣りの 1 サイクル

場面は次の順にくり返す。

1. 投げる(0.7 秒)
2. 待つ(1.5〜7.5 秒の一様な乱数。平均 4.5 秒)
3. 掛かる(0.5 秒)。このとき魚の種類が分かる。強い魚は 20%(D-029)。
4. 普通の魚:自動で巻き上げる(0.9 秒)→ 釣れる。
   強い魚:ミニゲーム(5.2)。
5. 結果を見せる(1.2 秒)→ 1 へ。

### 5.2 ミニゲーム(タイミング)

- 横長のゲージの上を、印が端から端まで 0.9 秒で往復する。
- ゲージの一部が当たり範囲(幅はゲージの 22%)。位置は乱数で決め、ゲージの端から 8% 以上はなす。
- 当たり範囲の中でタップすれば成功(釣れる)、外なら失敗(逃げられる)。境界ちょうどは成功。
- 5 秒タップしなければ逃げられる。

### 5.3 乱数

- 1 回の投げごとに、待ち時間 → 魚の種類 → (強い魚なら)当たり範囲の順に乱数を引く。
- 同じシードで同じタップをすれば、釣果の並びは完全に同じになる(D-021)。
- 数値は `src/core/config.js` にまとめてある。

## 6. 間違いや例外の扱い

- 画面が裏に回るなどで描画の間隔が空いても、1 回に進める時間は 0.1 秒までにする(一気に何匹も進まない)。
- ミニゲーム以外のタップは何もしない。

## 7. 用語集

| 用語 | 説明 |
| --- | --- |
| 計算本体 | `src/core/` にある、画面に関係しないゲームの決まりと乱数(D-028)。 |
| クリッカー | 放置やタップのくり返しで数が増えていくゲーム。 |
| ローグライク/ハクスラ | 1 回ごとに中身が変わる挑戦(ラン)で、拾った装備を組み合わせて強くなるゲーム。 |
| ラン | 1 回の挑戦。時間制(D-019)。 |
| シード | 乱数の出発点になる数。同じなら同じ乱数が出る。 |
| 当たり範囲 | ミニゲームで、タップすれば成功になるゲージの部分。 |
