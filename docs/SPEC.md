# 仕様(SPEC)

このプロジェクトが「何をするか」を書く文書です。「どう作るか」は [DESIGN.md](DESIGN.md) に書きます。

## 書式の見本

```
## 章の名前

- 決まっていること(関係する D 番号があれば書く)
- 未定のこと:……(DESIGN の「検討中の論点」へ)
```

---

## 1. 目的と範囲

- 目的:スマホのブラウザで動く、タップ主体の釣り×ローグライク/ハクスラ(ランごとに変わる装備で強くなるゲーム)のゲームを作る。放置で進む作りにはしない。操作がないと釣果は増えない(D-053)。
- 目標の姿:「掛かった瞬間の合わせと、強い魚との駆け引き(体力制のミニゲーム)、ランごとに変わる装備の組み合わせで強くなっていく、タップ主体の釣りゲーム」。迷ったときは、これに近づくほうを選ぶ(D-054)。
- 進み方:全部の魚で、掛かったら「合わせ」のタップが要る。普通の魚は合わせで釣り上げ、強い魚は合わせのあと体力制のミニゲーム(D-055・D-056)。
- 戦闘は数値で見せる:体力のバー、ダメージの数字、確率で出るクリティカル、外したときの回復(D-068・D-069)。
- ランの終わり方:1 ランは数分の時間制。時間が尽きたら終わり、持ち帰った素材で強化する(D-019)。
- 経済の流れ:魚を釣ると「素材」と「ウロコイン」(ゲーム内のお金)が手に入る。素材は竿の強化、ウロコインはクレートガチャ(②-4)に使う(D-032・D-076)。
- 竿は進行度の軸。段階が上がると新しい魚が釣れるようになる。待ち時間や強い魚の出やすさは竿では変えない(D-033)。竿は素材で確実に強くなり、装備はガチャで運の要素がある(D-041)。
- 作る順番:①釣りの 1 サイクル → ②-1 魚の種類と報酬、竿の強化 → ②-2 合わせ・体力制・セーブコード → ②-3 戦闘の数値化 → ②-4 クレートガチャ・装備枠(糸・リール・ルアー、レア度・特性)→ ②-5(おもり・浮き・おまもり、グローブ、釣れるクレート)→ ③強化の拡張 → ④ローグライク・ハクスラ要素(時間制のラン)(D-076)。
- 今あるもの:①、②-1(魚の種類と報酬・竿の強化・保存・手応えの演出)、②-2(合わせ・体力制のミニゲーム・セーブコード)、②-3(体力のバー・ダメージ・クリティカル・戦闘の数値の表)(この文書の 5 章)。
- まだないもの:クレートガチャ、装備、自動合わせ、時間制のラン、ローグライク・ハクスラ要素、クラウド保存、魚の図鑑、音、2 つ目以降のミニゲーム、複数の釣り場。

### 1.1 これから作るもの(決まっていること)

- 装備の種類:糸・おもり・リール・浮き・ルアー・おまもり。通常のクレートから出る。釣れるクレートは出現率が低く、グローブ(特殊な装備枠)だけが出る(D-038)。
- クレートは現実のお金を使わず、排出率を画面に出す(D-039)。
- 新しい釣り場やボスの解放条件も、竿の段階にそろえる方針(D-037)。
- グローブの能力に「自動合わせ」をレアとして入れる方針(D-057)。
- 装備の役割:糸=制限時間の延長、リール=削るダメージ、ルアー=外したときの回復の軽減、おもり=待ち時間の短縮、浮き=合わせの受付時間の延長、おまもり=報酬の増加、グローブ=特殊能力(自動合わせなど、レア)。装備は 1 個ずつ別物で、レア度は 4 段階(ノーマル/レア/エピック/レジェンド)、ランダムな特性が 0〜3 個付く。持ち物から選んで付け替え、不要なものは分解して素材にする(D-072)。
- 特性は、数値型を土台に、条件発動型(連続で当てたとき、合わせが成功したとき など)とタグのシナジーが中心。ルール変更型は将来。1 つの特性は一文で言える内容にする(D-073)。
- クレートは木・鉄・金をウロコインで引く。排出率を画面に表示する。ガチャの乱数は別の系統(D-074)。
- 腕前型のクリティカル(当たり範囲の中心の帯でタップするとクリティカル)を、レア装備の能力として付けられるようにする(D-070)。
- 魚の側の性質(弱点・暴れ方)と装備との相性は、将来の控え(D-075)。

## 2. 使う人と使い方

- 縦持ちのスマホで、ブラウザから遊ぶ(D-020)。
- 操作はタップだけ。掛かったら合わせ、強い魚とはゲージを狙ってタップする。何もしなければ釣果は増えない。
- 公開の URL(GitHub Pages)をスマホで開けば、PC の準備なしに遊べる(D-043)。

## 3. 入力

- タップ(釣りの絵のどこでも)。掛かっている間は合わせ、ミニゲームの間は当たり範囲を狙うタップ、休みの間は再開。ほかの場面では何もしない。
- 竿の強化のボタン(画面の下)。素材が足りないときは押せない。
- 「データを消す」(画面の左下の小さな文字)。2 回続けて押したときだけ消える。
- 「セーブコード」(画面の下の小さな文字)。開いた窓で、書き出し・コピー・読み込みができる(D-059・D-081)。
- URL の `?seed=数` で、乱数のシードを固定できる(D-021・D-030)。付けないときは毎回ちがうシードになり、画面の右下に表示される。

## 4. 出力

- 画面は上・真ん中・下の 3 段(D-051)。
  - 上:ウロコインと素材の数。
  - 真ん中:釣りの絵と、今の場面の文(「待っています…」「掛かった!」「強い魚だ!」、結果は「アジが釣れた」「クロダイを釣り上げた!」「クロダイに逃げられた…」のように魚の名前つき。合わせを逃したときは「逃げられた…」、休みは「タップで再開」)。
  - 下:竿の強化のボタン(「竿 段階1→2 | 素材 10 | 新しい魚が釣れる」)、「データを消す」、「セーブコード」、シード。
- 掛かったとき:浮きの上に大きな「!」と、合わせの受付の残りを示す細いバー(D-081)。
- ミニゲーム:ゲージの上に数値つきの体力のバー(「40 / 60」)、下に制限時間の残りの細いバー(D-081)。
- 絵:空・水面・竿・糸・浮き・魚、ミニゲームのゲージ。画像素材は使わず、図形で描く。魚は種類ごとに色と大きさがちがう。
- 手応えの演出(D-042・D-051):釣れたら緑に光り「+n ウロコイン」「+n 素材」が浮かぶ。逃げられたら赤く光って揺れる。初めて釣れた魚は金色に光り「はじめて!」の帯が出る。竿を強化すると「竿が段階 n に!」が出る。合わせが成功すると白く小さく光り「合わせ!」が出る。ミニゲームで当たると、魚の近くにダメージの数字(「-10」)が浮かび小さく揺れる。クリティカルは大きなオレンジの数字と「CRITICAL!」が出て、大きめに揺れる。外すと回復の数字(「+10」)が桃色で出る(D-081)。
- 保存:ウロコイン・素材・竿の段階・一度でも釣れた魚を、ブラウザの中に保存する。再読み込みしても続きから遊べる(D-065)。
- セーブコード:同じ中身を `FISH2-(中身)-(印)` の形の 1 行の文字列に書き出す。別のブラウザで読み込めば続きから遊べる(D-059・D-065)。

## 5. 計算の中身

### 5.1 釣りの 1 サイクル

場面は次の順にくり返す。

1. 投げる(0.7 秒)
2. 待つ(1.5〜7.5 秒の一様な乱数。平均 4.5 秒)
3. 掛かる。このとき魚の種類が分かる。強い魚は全部の段階で 20%(D-033・D-062)。
   合わせの受付時間(普通の魚 1.5 秒、強い魚 1.1 秒)のうちにタップすると成功。過ぎたら逃げられる(5 へ)(D-055・D-062)。
4. 普通の魚:合わせが成功したら巻き上げる(0.9 秒)→ 釣れる。
   強い魚:合わせが成功したら体力制のミニゲーム(5.2)。
5. 結果を見せる(1.2 秒)。釣れたら、その魚の報酬(ウロコインと素材)が増える。逃げられたら何も増えない。→ 1 へ。
6. 合わせを 5 回続けて逃したら、投げ直しを止めて休む。画面をタップすると再開する(D-062)。

### 5.2 ミニゲーム(体力制)

- 強い魚は体力を持つ。合わせが成功すると、体力が最大の状態でミニゲームが始まる(D-056・D-078)。
- 横長のゲージの上を、印が端から端まで往復する。速さは強い魚ごとにちがう(5.4)。
- ゲージの一部が当たり範囲。幅は強い魚ごとにちがい、位置は乱数で決め、ゲージの端から 8% 以上はなす。
- 当たり範囲の中でタップすると、体力がダメージぶん減る。当たりのたびに確率でクリティカルが出て、ダメージが倍率ぶん増える(5.6)。当たったら、当たり範囲の位置が変わる。境界ちょうどは当たり。
- 外でタップすると、体力が回復する(最大はこえない)。
- 体力が 0 以下になったら釣り上げ(残りより大きいダメージの超過は切り捨て)。制限時間を過ぎたら逃げられる。どんな操作でも、掛かってから「受付時間+制限時間」のうちに必ず終わる。
- 限界:当たり範囲の幅はゲージの 10% より狭くしない。印は端から端まで 0.45 秒より速くしない(D-036・D-048)。

### 5.3 乱数

- 乱数は 2 つの系統に分ける(D-064)。
  - 魚の系統:シードから作る。1 回の投げごとに、待ち時間 → 魚 → (強い魚なら)ミニゲームの種の順に引く。プレイヤーの操作では引かない。
  - ミニゲームの系統:魚の系統から引いた種で、強い魚ごとに作る。当たったあとの当たり範囲の位置はここから引く。クリティカルは、この種から作ったクリティカル専用の小さな系統から、当たりのたびに 1 回引く(D-079)。
- 魚の乱数 1 回で、区分(普通/強い)と種類をまとめて決める(D-046)。
- 待ち時間と魚の並びは、同じシードなら操作によらず同じで、Issue #6・#8 のときとも同じ。クリティカルの確率を変えても変わらない。
- クリティカルの確率を 0% にすると、同じシードと同じ操作で、結果が Issue #8 のときと完全に同じになる。
- 同じシードで同じ操作(タップと強化)をすれば、ウロコイン・素材・竿の段階・釣果の並びは完全に同じになる(D-021)。
- 数値は `src/core/config.js`、魚の設定表は `src/core/fish.js` にある。

### 5.4 魚の一覧(D-045)

| 段階 | 普通の魚(ウロコイン/素材) | 強い魚(ウロコイン/素材、印が端から端まで、当たり範囲、体力、制限時間) |
| --- | --- | --- |
| 1 | アジ(1/1) | クロダイ(5/3、0.9 秒、22%、20、8 秒) |
| 2 | サバ(3/2) | スズキ(15/6、0.8 秒、19%、30、9 秒) |
| 3 | カワハギ(8/4) | ブリ(40/12、0.7 秒、16%、40、10 秒) |
| 4 | タチウオ(20/8) | カツオ(100/24、0.6 秒、13%、50、11 秒) |
| 5 | ヒラメ(50/16) | マグロ(250/48、0.52 秒、11%、60、12 秒) |

- 竿の段階 n では、段階 n 以下の魚だけが釣れる(D-035)。
- 区分の中では、新しい段階の魚ほど出やすい。重みは段階ごとに 2 倍(段階 3 なら 1:2:4)(D-046)。

### 5.5 竿の強化(D-047)

- 竿の段階は 1〜5。最初は 1。
- 素材を使って 1 つ上げる。必要な素材:1→2 が 10、2→3 が 30、3→4 が 80、4→5 が 200。ウロコインは使わない。
- 素材が足りないと強化できない。足りれば、必要な数だけ減る。
- 効果は「新しい魚が釣れる魚の一覧に加わる」だけ。新しい魚は、強化したあと次に投げるときから出る。

### 5.6 戦闘の数値の表とクリティカル(D-071・D-078・D-080)

戦闘は「戦闘の数値の表」を受け取って動く。装備なしの基本の表は次のとおり(`src/core/config.js` の `combat`)。

| 項目 | 基本の値 | 下限と上限 |
| --- | --- | --- |
| 通常ダメージ | 10 | 1 以上(整数に四捨五入) |
| クリティカルの確率 | 10% | 0〜100% |
| クリティカルの倍率 | 2 倍 | 1〜10 倍 |
| 外したときの回復 | 10 | 0 以上(整数に四捨五入) |
| 制限時間の増減 | 0 秒 | 魚ごとの制限時間に足した結果が 1 秒以上 |

- 表の値が範囲の外なら境目の値に、数でない値は基本の値に直して使う。
- クリティカルのダメージは「通常ダメージ × 倍率」を四捨五入した整数(通常ダメージより小さくしない)。
- クリティカルが出なければ、必要な当たりの回数は「体力 ÷ 10」回(Issue #8 と同じ)。確率 10%・2 倍のときの平均は、クロダイ約 1.9 回、スズキ約 2.8 回、ブリ約 3.7 回、カツオ約 4.6 回、マグロ約 5.5 回。
- クリティカルの判定は、規則の一覧のどれか 1 つに当てはまれば成立。今の規則は「乱数が確率より小さい」だけ。

## 6. 間違いや例外の扱い

- 画面が裏に回るなどで描画の間隔が空いても、1 回に進める時間は 0.1 秒までにする(一気に何匹も進まない)。
- ミニゲーム以外のタップは何もしない。
- 保存データが壊れている・形がちがう・版がちがうときは、エラーにせず初めの状態から始める(D-065)。版 1 の保存データは版 2 に読み替える。
- セーブコードが空・形がちがう・壊れている(印が合わない)・版がちがう・数が範囲外のときは、短いエラーを出し、いまの保存データは一切変えない。読み込みの前に「上書きしますか?」を確かめる(D-065・D-081)。
- ブラウザの設定で保存が使えないときも、保存せずに遊べる。

## 7. 用語集

| 用語 | 説明 |
| --- | --- |
| 計算本体 | `src/core/` にある、画面に関係しないゲームの決まりと乱数(D-028)。 |
| クリッカー | 放置やタップのくり返しで数が増えていくゲーム。 |
| ローグライク/ハクスラ | 1 回ごとに中身が変わる挑戦(ラン)で、拾った装備を組み合わせて強くなるゲーム。 |
| ラン | 1 回の挑戦。時間制(D-019)。 |
| ウロコイン | ゲーム内のお金。クレートガチャに使う(D-032)。 |
| 素材 | 竿の強化に使う(D-032・D-049)。 |
| 竿の段階 | 進行度。上がると新しい魚が釣れる(D-033)。 |
| クレート | 装備が出る箱。ウロコインで引くガチャ(②-3)。 |
| 合わせ | 魚が掛かった瞬間のタップ。受付時間を過ぎると逃げられる(D-055)。 |
| 体力(HP) | 強い魚の粘り強さ。ミニゲームの当たりで減り、ゼロで釣り上げ(D-056)。 |
| セーブコード | 進み具合を 1 行の文字列にしたもの。別のブラウザに持ち出せる(D-059)。 |
| チェックサム | 中身から計算する短い数。中身が壊れると値が合わなくなる(D-065)。 |
| クリティカル | 当たりのときに確率で出る大成功。ダメージが倍率ぶん増える(D-068)。 |
| 戦闘の数値の表 | ダメージ・クリティカルの確率と倍率・回復・制限時間の増減をまとめたデータ。装備が書き換える(D-071)。 |
| シード | 乱数の出発点になる数。同じなら同じ乱数が出る。 |
| 当たり範囲 | ミニゲームで、タップすれば成功になるゲージの部分。 |
