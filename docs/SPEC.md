## 1. 目的と範囲

- 目的:スマホのブラウザで動く、タップ主体の「釣り×ハクスラ」(拾った装備で強くなるゲーム)を作る。放置で進む作りにはしない。操作がないと釣果は増えない(D-119)。
- 目標の姿:「掛かった瞬間の合わせと、強い魚との体力制の駆け引き、ガチャで集めた装備(スキルの組み合わせ)で強くなっていく、長く遊べる釣りゲーム。ガチャのドキドキが核」。迷ったときは、これに近づくほうを選ぶ(D-119)。
- 進み方:全部の魚で、掛かったら「合わせ」のタップが要る。合わせは「縮む輪」でタイミングを見て押す(連打は通用しない)。弱い魚は合わせで釣り上げ、強い魚は合わせのあと体力制のミニゲーム(D-056・D-082)。ヌシは自分で挑む、合わせなしの体力制の戦い(D-129)。
- 戦闘は数値で見せる:体力のバー、ダメージの数字、確率で出るクリティカル、ミスしたときの回復(D-068・D-069)。
- 時間制のランとローグライクの要素は作らない(D-119)。
- 経済の流れ:魚を釣ると「ウロコイン」(ゲーム内のお金)が手に入り、強い魚とヌシからは、その魚の「鱗」も手に入る。鱗は竿の製作と進化、ウロコインはクレートガチャ(②-4a)に使う(D-097・D-112)。
- 魚は 3 区分:弱い魚(稼ぎ)・強い魚(進行の鱗)・ヌシ(段階の締めくくり)(D-094・D-095)。
- 竿は進行度の軸。各段階で「製作 → ヌシ撃破 → 進化」と進み、進化すると次の段階の魚が釣れる(D-098)。竿は強さの効果を持たず、待ち時間や強い魚の出やすさも変えない(D-100)。
- 作る順番:①釣りの 1 サイクル → ②-1 魚の種類と報酬、竿の強化 → ②-2 合わせ・体力制・セーブコード → ②-3 戦闘の数値化 → ②-3b 合わせのタイミング化とバージョン表記 → ②-3c 魚の 3 区分・鱗・竿の製作と進化・ヌシ戦 → ②-3d ドロワーメニューと魚の表の整理 → ②-4a クレートガチャ・装備枠 → ②-4a2 UI の作り直し(目次と全画面)→ ②-4b スキル(数値型 10 個)・追加クリティカル・セーブコードの短縮 → ②-4b2 条件発動型のスキル・ルアーの作り直し・用語の統一 → ②-4b3 ゲージ系スキル(芯・縁)・完全レベル制・目利きの廃止 → ②-4b4 デバッグ画面・満タンの警告・スキル画面のグループ分け → ②-4c 土台(魚の入れ替え・数値の式・互換性を切る・保存の作り直し・限界の確かめ)→ ②-4c 防御(防御と貫通・魚側の強化・ヌシ戦の調整・会心の見直し)→ 装備のロック(保存の版 2)→ 戦闘の調整(会心 1.3・ジャストの初撃・ガチャ 60 秒)→ 餌と自動分解 → ②-4d 釣り場 → ②-5a おもり・浮き・おまもり → ②-5b グローブの基盤と能力 5 個 → ②-5c 残りの能力 5 個 → 川・沖と遊びの記録 → バランスの調整(ガチャ 4 倍・ヌシを強く・持ち物 300)→ ドット絵の見本 → ヌシの調整(制限時間)→ 外洋・深海 → バランスの見直し(土台 → ヌシのくせ)→ 背景の見本(港)→ ほかの背景 → 魚の量産 → 降臨 → デザインの土台・手応え・演出 → ③ 長期の遊びの支え(D-281・D-379・D-396)。
- 今あるもの(②-4b4 まで):①、②-1(魚の種類と報酬・竿の強化・保存・手応えの演出)、②-2(合わせ・体力制のミニゲーム・セーブコード)、②-3(体力のバー・ダメージ・クリティカル・戦闘の数値の表)、②-3b(縮む輪の合わせ・ジャスト・バージョン表記)、②-3c(魚の 3 区分・魚ごとの鱗・竿の製作と進化・ヌシ戦・数の短い表示)、②-3d(魚の表の整理)、②-4a(クレートガチャ・糸・リール・ルアー・保存の版 4)、②-4a2(目次のドロワーと全画面の画面:装備・クレート・素材・ステータス・設定)、②-4b(スキルレベル制の数値型 10 個・追加クリティカル・スキルの画面)、②-4b2〜②-4b4・②-4c・装備のロック・戦闘の調整・餌と自動分解(この文書の 4・5 章)。
- まだないもの:魚の図鑑、音、2 つ目以降のミニゲーム、外洋・深海の釣り場、初見向けの案内。

- ヌシの調整:ヌシの制限時間を、目標の命中回数に合わせて短くした(目標の命中回数 × 印が 1 回通る時間 × 1.5。下限 8 秒。g=1〜2 はこれまでのまま)。ノーマルとレアだけの装備が時間切れで届かないようにするため。遊びの記録に、ガチャで引いた装備と釣れたグローブのレア度ごとの個数を足した(D-366・D-368。くわしくは 5.4.1・5.15)。
- バランスの調整:ガチャの目標の時間を 15 秒に(価格は 4 分の 1)、育てた装備を選ぶ引く回数の合計 T(g) を 6 倍に(g=1 で 180・g=100 で 1800)、ヌシの体力を測り直し、持ち物 300 個(警告は残り 30 個)。遊びの記録にガチャの回数・遊んだ時間・稼いだウロコインと鱗を足した(D-351〜D-358。くわしくは 5.4.1・5.8・5.15)。
- 川・沖と遊びの記録:釣り場 川(g=11〜15)・沖(g=16〜20)を表のデータだけで足した。戦闘ごとの命中・かすり・ミスなどを、ゲームの保存とは別の場所に記録し、`?debug` のデバッグ画面で見てコピーできる(D-345〜D-350。くわしくは 5.13・5.15)。外洋・深海は、あとで足す。

- ②-4a で作るもの:クレートガチャ(クレートの画面、1 回引きと 10 連=10 倍の価格、画面全体の演出)、糸・リール・ルアーの 3 枠、持ち物(上限あり、空きが足りないと引く前に止める)、分解(ウロコインが価格の 1 割前後返る)、保存の版 4 とセーブコード `FISH4`。ガチャの乱数の種は、データを作ったときに決めて保存する(D-137〜D-143)。

- 装備の入手はガチャ(クレート)だけ。天井や、運が悪い期間の保険は入れない。ウロコインだけで引き、現実のお金は使わない。排出率を画面に出す(D-039・D-120)。
- ガチャは 1 回引きと、まとめ引き(10 連)。まとめ引きは演出を飛ばせる。引く演出(溜めと、レア度が分かる瞬間)が核(D-121)。
- クレートは竿の段階ごとに 1 種類(名前は魚や釣り場にちなむ)。価格とグレードは段階の数式。価格は「段階ごとの毎秒の稼ぎ × 目標の時間」で、1 回分が貯まる時間を各段階で 1〜3 分に収める。古いクレートも引けるが、後半では割に合わない。ガチャの乱数は別の系統(D-122)。
- 装備の種類:糸・おもり・リール・浮き・ルアーの 5 種類が通常のクレートから出る。お守りは降臨専用の枠で、ガチャでは出ない(D-394・D-396)。釣れるクレートは出現率が低く、グローブ(特殊な装備枠)だけが出る(D-038)。
- 装備は生成型:種類 × レア度 × グレード × スキルの抽選で自動で作り、名前は段階の魚にちなむ(例:クロダイの糸)。基本効果が 1 つ(グレードの範囲でばらつく)と、スキルが 0〜3 種類。レア度は 4 段階(ノーマル/レア/エピック/レジェンド)。同じものは分解して素材にできる。付け替えて使う(D-123)。
- 基本効果:糸=制限時間、リール=ダメージ、ルアー=命中範囲の広さ +n%(D-181)、おもり=報酬(ウロコイン +%。版 8 から:D-394)、浮き=合わせの成功帯とジャスト帯、お守り=降臨で授かる専用の能力(静め・刻・破り・和らぎ。付けている 1 つだけ効く:D-396・D-397。くわしくは 5.17)、グローブ=特殊能力(自動合わせなど、レア)(D-057・D-123・D-127)。
- スキル:装備に「スキル名 + レベル」(例:会心率 Lv2)が付き、装着中の装備のレベルの合計でスキルレベルが決まる(D-195)。頭打ち型は俊敏・見極め・名人技・回復の軽減の 4 つで最大 Lv3。ほかは成長型で、最大レベルは段階で伸びる(D-125)。会心率は 100% を超えると追加クリティカル(D-126)。
- 魚の防御(割合型)と、スキルの貫通(D-128)。
- 装備なしで釣れるのは序盤(段階 1〜2 目安)の強い魚だけでよい。詰み防止として、弱い魚でウロコインは増え続ける(D-102・D-129)。
- 新しい釣り場の解放条件も、竿の段階にそろえる方針(D-037)。
- 腕前型のクリティカル(命中範囲の中心の帯でタップするとクリティカル)は、②-4b3 のゲージ系スキル「芯」に統合する。ゲージ系は「芯」(中央の帯で命中するとダメージ・会心率)と「縁」(縁のぎりぎりで命中するとダメージ大)だけ。命中範囲を広げるのはルアーの役目(D-197)。
- 魚の側の性質(弱点・暴れ方)と装備との相性は、将来の控え(D-075・D-132)。

## 2. 使う人と使い方

- 縦持ちのスマホで、ブラウザから遊ぶ(D-020)。
- 操作はタップだけ。掛かったら合わせ、強い魚とはゲージを狙ってタップする。何もしなければ釣果は増えない。
- 公開の URL(GitHub Pages)をスマホで開けば、PC の準備なしに遊べる(D-043)。

## 3. 入力

- タップ(釣りの絵のどこでも)。掛かっている間は合わせ、ミニゲームの間は命中範囲を狙うタップ、休みの間は再開。ほかの場面では何もしない。
  - 合わせと命中は、指が触れた瞬間の時刻(押した時刻)で判定する。処理が遅れても判定は変わらない(D-284・D-289)。
  - 絵の領域では、ダブルタップの拡大・スクロール・長押しの選択とメニューは出ない(D-289)。
  - 合わせと戦闘の間(掛かってから結果まで)は、保存と上の欄の書き換えを後回しにし、場面が終わったら保存する。ページを離れる・隠れるときは、すぐ保存する(D-284)。
- 竿のボタン(画面の下)。工程で 1 つのボタンが切り替わる(4 章)。押せないときは灰色。
- ☰(釣りの絵の右上)。押すと、右から目次が出る。もう一度押す(✕)か、外側をタップすると閉じる(D-130・D-152)。
- 全画面の「←」と、スマホの「戻る」(D-161)。
- 目次と全画面の中のタップと、外側のタップは、釣りの操作(合わせ・ミニゲーム・竿のボタン)に数えない。
- クレートの画面の「1 回引く」「10 連」、装備の画面の「付ける」「外す」「分解」「まとめて分解」「ロックする/ロックを外す」「まとめてロック」「まとめて解除」(D-139・D-162・D-246)。引く演出は、タップで結果まで飛ばし、結果でタップすると閉じる。
- 「データを消す」(設定の画面)。3 秒のうちに 2 回続けて押したときだけ消える。
- 「セーブコード」(設定の画面)。書き出し・コピー・読み込みができる(D-059・D-092)。
- URL の `?debug&seed=数` で、乱数のシードを固定できる(D-021・D-030)。`?debug` がないと効かない(本番に影響しない:D-215)。付けないときは毎回ちがうシードになり、画面の右下に表示される。確認用の仕組みの全部は 5.11。

## 5. 計算の中身

### 5.1 釣りの 1 サイクル

場面は次の順にくり返す。

1. 投げる(0.7 秒)
2. 待つ(1.5〜7.5 秒の一様な乱数。平均 4.5 秒)
3. 掛かる。このとき魚の種類が分かる。強い魚は全部の段階で 10%、残りは弱い魚(D-113)。ヌシはここでは出ない。
   「!」が出て、浮きに向かって輪が縮む(5.7)。輪が成功帯にあるうちにタップすると成功。輪が大きいうち(早すぎ)か、通り過ぎるまでタップしない(遅すぎ)と逃げられる(5 へ)(D-082)。「!」の前のタップは何も起きない。
4. 弱い魚:合わせが成功したら巻き上げる(0.9 秒)→ 釣れる。ジャストでも結果は同じ(表示だけ)。
   強い魚:合わせが成功したら体力制のミニゲーム(5.2)。ジャストなら最初の命中が 1.5 倍(5.7)。
5. 結果を見せる(1.2 秒)。釣れたら、その魚の報酬(ウロコインと、強い魚なら鱗 1)が増える。逃げられたら何も増えない。→ 1 へ。
6. 合わせを 5 回続けて逃したら(早すぎ・遅すぎのどちらも数える)、投げ直しを止めて休む。画面をタップすると再開する。成功すると数え直す(D-082・D-087)。

### 5.2 ミニゲーム(体力制)

- 強い魚は体力を持つ。合わせが成功すると、体力が最大の状態でミニゲームが始まる(D-056・D-078)。
- 横長のゲージの上を、印が端から端まで往復する。速さは強い魚ごとにちがう(5.4)。
- ゲージの一部が命中範囲。幅は強い魚ごとにちがい、位置は乱数で決め、ゲージの端から 8% 以上はなす。
- 命中範囲の中でタップすると、体力がダメージぶん減る。命中のたびに確率でクリティカルが出て、ダメージが倍率ぶん増える(5.6)。命中したら、命中範囲の位置が変わる。境界ちょうどは命中。ルアーを付けると、命中範囲の幅が広がる(真ん中の位置はそのまま:5.8)。
- 外でタップすると(ミス)、体力が回復する(最大はこえない)。ミスのボーナスはない。連撃は途切れる(5.10)。
- 芯・縁(D-197・D-209):命中範囲を中心からの距離で 芯(0.3 以下)・通常・縁(0.75 以上)に分ける。帯は命中範囲の幅に比例する(ルアーで広がると帯も広がる)。芯か縁のスキルを付けているときだけ、ゲージの命中範囲の中に芯(濃い緑)と縁(両端の金色)を重ねて見せる。命中したとき、芯なら「芯」、縁なら「縁」と短く出て、数字も同じ色になる。
- 画面:体力のバーの上に、左に「連撃 ×3」(2 段から)、右に次の命中で効く条件の短い名前(先手・勢い・先制・とどめ。持っているスキルだけ)。条件発動型が効いた命中は、数字の色が変わる(水色)。
- 体力が 0 以下になったら釣り上げ(残りより大きいダメージの超過は切り捨て)。制限時間を過ぎたら逃げられる。どんな操作でも、掛かってから「受付時間+制限時間」のうちに必ず終わる。
- 限界:命中範囲の幅はゲージの 10% より狭くしない。印は端から端まで 0.45 秒より速くしない(D-036・D-048)。

### 5.3 乱数

- 乱数は 2 つの系統に分ける(D-064)。
  - 魚の系統:シードから作る。1 回の投げごとに、待ち時間 → 魚 → (強い魚なら)ミニゲームの種の順に引く。プレイヤーの操作では引かない。
  - ミニゲームの系統:魚の系統から引いた種で、強い魚ごとに作る。命中したあとの命中範囲の位置はここから引く。クリティカルは、この種から作ったクリティカル専用の小さな系統から、命中のたびに 1 回引く(D-079)。
  - ヌシ戦の系統:シードと「何回目の挑戦か」から作る。魚の系統は使わない(D-115)。
  - 餌の投:魚の系統はいつもどおり(待ち時間 → 魚 → ミニゲームの種)引き、その投の魚だけを現在の段階の強い魚に置き換える。ミニゲームの種は、シードと投げた回数から作る別の系統から引く。餌を使っても使わなくても、以後の魚の並びは同じ(D-264・D-271)。
  - 釣り場を移っても、魚の乱数はいつもどおり引く。投げている・待っている投は、引いた数のまま、新しい釣り場の魚に決め直す(D-275・D-282)。
- 魚の乱数 1 回で、区分(弱い/強い)と種類をまとめて決める(D-046)。
- 待ち時間と魚の並びは、同じシードなら操作(ヌシ戦を含む)によらず同じ。クリティカルの確率を変えても変わらない。強い魚の出現率を 10% にしたので、並びは ②-3b までとはちがう(記録は `tests/fixtures/fish_order.json`)(D-113)。
- 同じシードで同じ操作(タップと竿のボタン)をすれば、ウロコイン・鱗・竿の段階と工程・釣果の並びは完全に同じになる(D-021)。
- 数値は `src/core/config.js`、魚と段階の設定表は `src/core/fish.js` にある(D-111)。

#### 5.4.1 魚の数値の式(g は通し番号。数は `config.formula`、式の形は `src/core/formula.js`)

- ウロコイン:弱い魚 = 1 × 倍率(g)、強い魚 = 弱い魚の 5 倍、ヌシ = 強い魚の 10 倍。上から 2 けたに丸める。倍率(g)は、段 k → k+1 の伸び(指数)を 1.1 × 10 ÷(10 + k − 1)にしたもの(1 段ごとの伸びがだんだん下がる:g=2〜5 で約 3・8・20・48 倍、g=100 で約 4.3 × 10^11 倍。1 段ごとの伸びは g=100 で約 1.1 倍)。
- 鱗:強い魚とヌシは 1 枚(弱い魚は 0)。
- ヌシのくせ(D-379・D-381・D-382):釣り場ごとに 1 つ(港はなし)。その釣り場のヌシ全部に付き、4・5 体目は 1 つ前の釣り場のくせも重ねる。
  - 磯:狭い命中範囲。命中範囲 × 0.6(ふつうは 10% → 6%)。対策はルアー(命中範囲)・芯と縁。
  - 川:防御の壁。防御 = max(102%, ふつうの貫通 + 20%)。ふつうの貫通は、目安の引く回数の装備の中央値(貫通 Lv = min(2 + g, 9 + 2 ×(g − 11)))。貫通なしでは 1 命中 1 ダメージで、ミスの回復に負ける。対策は貫通。
  - 沖:速い印。印の速さ × 0.66(安全の下限 0.3 秒まで。0.45 秒 → 0.3 秒)。対策は、お守りの「静め」(印を遅くする。版 8 から:D-394)。
  - 外洋:自動回復。1 秒ごとに、最大の体力の 1% を回復する(戦闘の画面に「回復 +n/秒」)。対策は短い時間で削る火力。
  - 深海:短い制限時間。制限時間 × 0.5(約 24 秒 → 12 秒)。糸・粘りで延びる上限は、くせの前の制限時間で数える(最大で約 36 秒)。対策は糸・粘り。
  - 命中範囲と印の速さの下限:ふつうの魚は 10%・0.45 秒。くせのあるヌシは、安全の下限 5%・0.3 秒まで狭く・速くなってよい。
- 防御:強い魚は 0%。ヌシは防御の壁のくせのときだけ(実効防御 = 防御 − 貫通、100% 以上はダメージ 1)。
- 体力:強い魚 10 + 10g。ヌシは 64.1 × g^0.9323 × 1.1425^g(版 8 で 0.85 倍にした:D-395) を上から 2 けた(g=1 で 73、g=10 で 2100、g=30 で 83000)に、くせの補正(狭い命中範囲 × 0.52・防御の壁 × 0.46・速い印 × 1・自動回復 × 0.69・短い制限時間 × 0.69。重なると掛け合わせ)を掛けて、もう一度 2 けたに丸める。g=1〜2 は 120 まで(D-358)。
  - 係数は、目安の引く回数 P(g) で引いた装備と、ふつうの遊び方で、80% 勝つ体力にシミュレーションで合わせ、全体を 0.9 倍にした(D-380・D-381・D-382)。
  - シミュレーションの命中は、押すタイミングのぶれ(時間)で決める。くせのない幅と印の速さで 80%。ルアーで広げる・印を遅くすると当たりやすく、速い印では外れやすい。押す間隔は人の側で決まる(くせのない印の 2 回の通過ごと)。装備は、釣り上げるまでの時間から延長を引いた値で選ぶ(D-382)。
  - P(g) = 20 × 1.06375^(g − 1) を四捨五入(g=1 で 20 回、g=30 で 120 回)。前の段階の分も、その段階のクレートを P(h) 回ずつ引いて持っている前提。
  - g=31 から先は、釣り場を足すときに合わせ直す。
- 制限時間:強い魚 8 秒 + 4 秒 × log5(g)、ヌシ 20 秒 + 2 秒 × log5(g)(0.1 秒に丸める。g=30 のヌシで 24.2 秒)。糸・粘りなどの延長は、その魚の制限時間まで(合計で最大 2 倍:D-380)。短い制限時間のくせのヌシは、くせの前の制限時間まで延びる(D-382)。
- 印の速さ(端から端):強い魚 1000 − 100g ミリ秒、限界 450 で止まる。命中範囲の幅:強い魚 0.25 − 0.03g、限界 10% で止まる。ヌシは強い魚の 1 段先の値。
- 製作に要る鱗:3 + 7 ×(1 − e^(−(s−1)÷8.7))を四捨五入(s は釣り場の中の位置。どの釣り場も 3・4・4・5・6:D-282)。進化はヌシの鱗 1。
- クレートの価格は 5.8 の式(魚の報酬から)、装備の基本効果のグレードの倍率は 1 + 0.35(g − 1)、成長型のスキルの最大レベルは 2 + g(5.9)。
- g=1〜5 は ②-4b4 のときの手書きの値の ±15% 以内(テストが確かめる。クレートの価格は戦闘の調整でおよそ半分にした:D-253)。g=100 でも安全な整数の範囲に収まる(ヌシのウロコイン 21 兆、クレートの価格 4.7 兆)。

- いる釣り場の魚だけが釣れる(D-275)。いちばん新しい釣り場では、釣り場の最初の段階〜竿の段階の弱い魚と強い魚。古い釣り場では、その釣り場の全段階。ヌシは「ヌシに挑む」でだけ出る。
- 区分の中では、新しい段階の魚ほど出やすい。重みは釣り場の中の位置で 2 倍ずつ(段階 3 なら 1:2:4。磯の段階 3 も 1:2:4)(D-046・D-275)。
- 時間あたりのウロコインは、強い魚が弱い魚の約 4〜5 倍(D-095)。弱い魚だけでもウロコインは増え続ける(詰まない)。

### 5.5 竿の製作と進化、ヌシ戦(D-098・D-101・D-115・D-225・D-253)

- 竿の製作は通過点で、関門にはしない。関門になっているのは、ヌシ戦と、ヌシの竿への進化(D-212)。

- 竿は段階(通し番号 g。港 1〜5・磯 6〜10・川 11〜15・沖 16〜20)と工程を持つ。最初は段階 1 の未製作。画面では「磯 段階 2」のように、釣り場の中の段階で言う。
- 工程:未製作 →(その段階の強い魚の鱗で)製作済み →(ヌシに勝つ)ヌシ撃破 →(ヌシの鱗 1 で)次の段階の未製作。
- 製作に要る鱗(式:5.4.1):クロダイ 3・スズキ 4・ヒラメ 4・ワラサ 5・ブリ 6、メジナ 3・イシダイ 4・ブダイ 4・イシガキダイ 5・クエ 6。ウロコインは使わない。足りれば必要な数だけ減る。
- 港の 5 段階目(ヌシ・ブリ)を倒して進化すると、磯が解放され、自動で磯に移る(5.13)。磯の 5 段階目(ヌシ・クエ)で川、川の 5 段階目(ヌシ・イトウ)で沖、沖の 5 段階目(ヌシ・キハダ)で外洋、外洋の 5 段階目(ヌシ・クロマグロ)で深海が解放される。深海の 5 段階目(ヌシ・シーラカンス)を倒して進化すると「進化済み」で止まる(エラーにならない)。ボタンは「次の釣り場はまだない」。「最後のヌシ」はなく、釣り場はあとから足し続ける(D-277・D-347・D-375・D-377)。
- 製作・ヌシ戦・進化は、いちばん新しい釣り場でだけできる(D-274)。
- 進化の効果は「次の段階の魚が釣れる魚の一覧に加わる」だけ。次に投げるときから出る。
- ヌシ戦:製作済みかヌシ撃破のとき、投げる・待つの間だけ挑める。待っていた魚は取っておき、合わせなしで体力制の戦い(5.2・5.6 と同じ決まり)から始める。勝つとヌシの鱗 1 とウロコイン。負けても何も減らず、何度でも挑める。終わったら、取っておいた魚から釣りを続ける。
- 竿の名前:未製作は前の段階のヌシの釣竿(段階 1 は「はじめの釣竿」)、製作済み・ヌシ撃破は「クロダイの釣竿」、進化すると「ヌシ・クロダイの釣竿」。
- 製作までの目安(上手に遊ぶ場合・段階 g の平均的な装備で。重いテストで測る):釣り場の段階 1 約 3.2〜3.4 分、2 約 7.7 分、3 約 10 分、4 約 16 分、5 約 18 分(どの釣り場もほぼ同じ。段階 100 でも約 18 分:D-253・D-282)。

### 5.6 戦闘の数値の表とクリティカル(D-071・D-078・D-080)

戦闘は「戦闘の数値の表」を受け取って動く。装備なしの基本の表は次のとおり(`src/core/config.js` の `combat`)。

| 項目 | 基本の値 | 下限と上限 |
| --- | --- | --- |
| 通常ダメージ | 10 | 1 以上(整数に四捨五入) |
| クリティカルの確率 | 10% | 0〜100% |
| クリティカルの倍率 | 1.3 倍(戦闘の調整で 1.5 倍から:D-255) | 1〜100 倍 |
| ジャスト倍率 | 3 倍(強い魚のジャストの初撃:D-256) | 1 以上(安全上限 100 万) |
| 貫通 | 0% | 0 以上(魚の防御から引く割合:D-235) |
| ミスしたときの回復 | 10 | 0 以上(整数に四捨五入) |
| 制限時間の増減 | 0 秒 | 魚ごとの制限時間に足した結果が 1 秒以上 |

- 表の値が範囲の外なら境目の値に、数でない値は基本の値に直して使う。
- クリティカルのダメージは「通常ダメージ × 倍率」を四捨五入した整数(通常ダメージより小さくしない)。
- 会心率・倍率・貫通・ジャスト倍率の合計の逓減(D-255・D-257・D-260):会心率は 115%、倍率は 1.65 倍、貫通は 70%、ジャスト倍率は 5.1 倍までそのまま(会心率 Lv7・会心威力 Lv7・貫通 Lv7・ジャスト・ブースト Lv7 の値)。こえた分は「こえた量 = soft × ln(1 + こえた量 ÷ soft)」(soft は会心率 0.5・倍率 0.25・貫通 0.25・ジャスト倍率 1)に縮める。増え方はだんだん小さくなるが、合計は止まらずに増え続ける。どのスキルから来た会心率(連撃・心、勢い、先制、芯など)も、合計にかける。
- 防御で減らす(D-235):命中のダメージは、通常の計算(下の 5.10)のあとに、実効防御(防御 − 貫通、下限 0)で減らす。ダメージ = max(1, 丸め(ダメージ ×(1 − 実効防御)))。実効防御 100% 以上はいつも 1(クリティカルを重ねても 1)。
- クリティカルが出なければ、防御のない魚では、必要な命中の回数は「体力 ÷ 10」回。
- クリティカルの判定は、規則の一覧のどれか 1 つに当てはまれば成立。今の規則は「乱数が確率より小さい」だけ。

### 5.7 合わせ(縮む輪)とジャスト(D-082・D-084・D-087・D-088・D-256〜D-258)

輪は「!」と同時に縮み始める。時間は「!」からの経過で、乱数は使わない。

| 魚 | 早すぎ | 成功帯 | そのうちジャスト帯 | 遅すぎ |
| --- | --- | --- | --- | --- |
| 普通の魚 | 0〜1.0 秒 | 1.0〜1.6 秒 | 1.2〜1.4 秒 | 1.6 秒で通り過ぎる |
| 強い魚 | 0〜0.8 秒 | 0.8〜1.2 秒 | 0.93〜1.07 秒 | 1.2 秒で通り過ぎる |

- 区間は始まりを含み、終わりを含まない。
- 数値は戦闘の数値の表の `hook` にある。下限:輪 1.0 秒以上、成功帯 0.25 秒以上、ジャスト帯 0.10 秒以上、早すぎの区間 0.3 秒以上。強い魚の帯は普通の魚の帯より広くしない。範囲の外の値は丸める。
- 強い魚のジャストの初撃(D-256):合わせがジャストの瞬間に、魚の体力に「初撃」が入る。初撃 = 1 命中の基本のダメージ(通常ダメージ + リール + 強打など)× ジャスト倍率(基本 3 倍 + ジャスト・ブースト、逓減つき)を四捨五入し、実効防御で減らす(最小 1)。クリティカルの判定はしない(乱数を引かない)。命中には数えない(連撃・勢い・先制・とどめ・芯・縁などは働かない。先手は初撃のあとの最初の命中に乗る。先制は初撃で体力が減るので効かない)。
- 初撃が体力以上なら、ミニゲームに入らず、その場で釣り上げ(結果の理由は「一撃」。鱗とウロコインは通常どおり)。届かないときは、体力が減った状態でミニゲームに入る。
- 通常の成功には初撃はない。ヌシ(挑戦・すぐ戦う)にも初撃はない。自動合わせ(グローブ、②-5)はジャストが出ないので、初撃もない。
- 弱い魚のジャスト(D-258):ウロコイン × 1.5。順番は 基本 × ジャスト倍率 × 豊漁 で、まとめて四捨五入(最小 1)。強い魚・ヌシのウロコインには掛けない。

### 5.8 クレートガチャと装備(D-120〜D-123・D-137〜D-149)

- クレートは段階ごとに 1 種類(名前は段階の強い魚から:クロダイのクレート …)。竿がその段階になると引ける。古いクレートも引ける。
- 価格(1 回):クロダイ 3・スズキ 7・ヒラメ 17・ワラサ 40・ブリ 93(目標の時間 60 秒のときの 12・28・67・160・370 の 4 分の 1)。10 連は 10 倍。価格 =(1 回投げたときのウロコインの期待値 ÷ 8.6 秒)× 15 秒 を、上から 2 けたに丸める。期待値は弱い魚のウロコインを × 1.35(ジャスト 70% の分)にして見積もる(D-253・D-260・D-355)。上手に遊ぶ(ジャスト 70%)と 1 回分が約 15 秒(シミュレーション上。実際は約 2 倍の約 30 秒)で貯まる。段階 1〜100 の全部で、上手なら 13〜20 秒、ときどき失敗(ジャストなし、命中の 3 割は外す)でも 23 秒以内(平均的な装備、重いテスト:D-355)。分解で戻るウロコインは価格の割合なので、価格と一緒に下がる。
- 1 回引くと、レア度 → 種類(糸・リール・ルアー・おもり・浮きの 5 種類から等しい確率。乱数を引く数は 3 種類のときと同じ:D-321・D-394)→ 基本効果の値 → スキル → 各スキルのレベル の順に決める。10 連はこれを 10 回(D-207)。
- 排出率:ノーマル 70%・レア 22%・エピック 6.5%・レジェンド 1.5%(全部のクレートで同じ)。
- 基本効果(グレード = クレートの段階):

| 種類 | 効果 | グレード 1・ノーマル | グレード 5・レジェンド |
| --- | --- | --- | --- |
| 糸 | 制限時間 +n 秒(0.1 秒刻み) | +0.5〜+1.0 秒 | +3.8〜+7.7 秒 |
| リール | 通常ダメージ +n | +1〜+2 | +8〜+15 |
| ルアー | 命中範囲の幅 +n%(幅 ×(1 + n%)。上限はゲージの 70%、下限 10%:D-181) | +5〜+8% | +38〜+58% |
| おもり | ウロコイン +n%(豊漁と足し算。版 8 から:D-394。版 7 までは印の速さ −n%) | +4.9〜+7.1% | +24.4〜+30.4% |
| 浮き | 合わせの成功帯とジャスト帯 +n%(成功帯は輪の 60%、ジャスト帯は成功帯の 50% まで:D-320) | +8.6〜+12% | +33.7〜+39.4% |

  範囲 = 基本の範囲 ×(1 + 0.35 ×(グレード − 1))× レア度の倍率(ノーマル 1・レア 1.5・エピック 2.2・レジェンド 3.2)。値は範囲の中でばらつく(D-147)。
  おもり・浮きは拮抗型(付けるほど伸びが小さくなる型)。値は「点」(基本 10〜15 点)で持ち、効果 = 上限 × 点 ÷(点 + k)(おもり:上限 60%・k 112、浮き:上限 60%・k 60)。画面には効果の割合を出す(D-327)。待ち時間を短くするのは、俊敏のスキルだけ。
- 装備の名前:グレードの段階の強い魚 + 種類(例:クロダイの糸、ブリのリール)。
- 装着:糸・リール・ルアー・おもり・浮きの 5 枠に 1 個ずつ(D-321・D-394)。お守りの枠は別(降臨で授かる。装備の画面のグローブの下)。効果は戦闘の数値の表に足し算する(D-181)。ヌシ戦にも効く。ルアーの例:レジェンド・グレード 1 で +16〜24%(クロダイ 22% → 最大 27.3%)、グレード 5 の最高 +58% でも、一番広いクロダイで 34.8%(上限 70% に届かない)。
- 持ち物は 300 個まで。空きが足りないと引けない(引いたものが黙って消えることはない)(D-140・D-355)。
- 排出率はどのクレートも ノーマル 70%・レア 22%・エピック 6.5%・レジェンド 1.5%(変えない)。1 回分が 15 秒で貯まるので、シミュレーション上の 1 時間に約 240 回引け、レジェンドは約 3.6 個、エピック以上は約 19 個(実際は約 2 倍の時間がかかる:D-355)。
- 育てた装備(戦闘の基準)を選ぶ引く回数の合計 T(g) = 6 × N(g)(N(g) = 30 × g^0.5 を四捨五入):g=1 で 180・2 で 252・5 で 402・10 で 570・20 で 804・50 で 1272・100 で 1800。1 段階を進める時間の目安は T(g) × 15 秒(g=1 で 45 分、g=100 で 7.5 時間。シミュレーション上:D-355)。
- 分解:返るウロコイン = その装備のグレードのクレートの価格 × レア度の割合(6%・12%・25%・50%)。平均で価格の約 9 %(D-137・D-149)。
- ロック:装備 1 個ごとに、ロックの有無を持つ(新しく引いた装備はロックなし)。ロック中は、まとめて分解の対象・個数・戻りの量に入らず、1 個ずつの分解もできない。付ける・外す・付け替えはできる。ロックはゲームの結果(魚・戦闘・ガチャ)に関係しない(D-246)。
- ガチャの乱数は、魚とミニゲームの乱数とは別。ガチャの種と引いた回数から決まるので、再読み込みしても引き直せない。ガチャ・装着・分解で、魚の並び(待ち時間と種類)は変わらない(D-141・D-148)。
- 装備を付けなければ、結果は ②-3d までと完全に同じ。おもり・浮き・おまもりを付けなければ、結果は ②-5a の前と同じ。

| 豊漁 | 成長 | ウロコイン +10%(端数は四捨五入。鱗を増やすスキルはない。1 匹から鱗は 1 枚しか取れないので、% で上げても意味がないため:D-211) |
| 俊敏 | 頭打ち | 待ち時間 −10%(1 秒より短くしない) |
| 見極め | 頭打ち | 合わせの成功帯 +0.1 秒 |
| 名人技 | 頭打ち | ジャスト帯 +0.04 秒 |
| 回復の軽減 | 頭打ち | ミスしたときの回復 −1/3(Lv3 で 0) |
| 貫通 | 成長 | 貫通 +10%(魚の防御から引く:D-236) |

- 会心率・会心威力・貫通・ジャスト・ブーストは、合計に逓減がかかる(5.6)。単独で付けたとき、会心率は Lv7 まで +15% ずつ、Lv8 で +13.1%、Lv10 で +8.6%、Lv20 で +3.2%、Lv100 で +0.5%(合計 Lv7 115%・Lv20 194.5%・Lv100 283.2%)。会心の倍率は Lv7 まで +0.05 ずつ、Lv8 で +0.046、Lv20 で +0.014(合計 Lv7 1.65 倍・Lv20 1.97 倍・Lv100 2.39 倍)。スキルの画面に「次のレベルでの増分」を出し、逓減が始まったら「(増え方が少し緩やかです)」と添える。
- 追加クリティカル:クリティカルの確率が 100% をこえると、整数の部分の段数は必ず起き、残りの確率でもう 1 段。ダメージ = 通常ダメージ × 倍率の段数乗。例:115% は 1 段 85%・2 段 15%(D-169)。
- 効かせる順:基本の表 → 装備の基本効果 → スキルの足し算 → スキルの掛け算(回復の軽減)→ 点検。装備とスキルがなければ、結果は ②-4a と同じ。

### 5.10 条件発動型のスキル(D-184〜D-187・D-191・D-192)

- 全て成長型(最大は「2 + 竿の段階」)。条件を満たした命中にだけ効き、戦闘の数値の表(今の値)は変えない。

| スキル | 条件 | 1 レベルの効果 |
| --- | --- | --- |
| 連撃・攻 | 連続命中 1 段ごと(最大 10 段) | ダメージ +1 |
| 連撃・心 | 連続命中 1 段ごと(最大 10 段) | 会心率 +3% |
| 先手 | 合わせ成功(ジャストを含む)のあとの最初の命中。ヌシ戦は始まりで効く | ダメージ +4 |
| ジャスト・ブースト | 強い魚のジャストの初撃(ヌシ戦では効かない:D-257) | ジャスト倍率 +0.3(「強い魚のジャストの初撃 +0.3 倍」) |
| とどめ | 魚の体力が最大の 25% 以下(ちょうどを含む) | ダメージ +15% |
| 勢い | クリティカルが出た次の命中(1 回だけ。ミスでは消えない) | 会心率 +10% |
| 先制 | 魚の体力が満タンで、その戦闘の最初の命中まで | 会心率 +10% |
| 芯(ゲージ系) | 命中範囲の芯(中心からの距離 0.3 以下)で命中 | 会心率 +10%(その命中だけ) |
| 縁(ゲージ系) | 命中範囲の縁(中心からの距離 0.75 以上)で命中 | ダメージ +20% |

- 連撃の段数:続けて命中した回数。命中のダメージには「その前までの段数」を使う(1 回目は 0 段)。ミスで 0 に戻り、戦闘が終わると消える。
- 命中 1 回の計算の順:基本のダメージ(表 + 連撃・攻 × 段数 + 先手)→(1 + とどめ + 縁)を掛けて四捨五入 → クリティカルの段数の倍率 → 実効防御で減らす(最小 1)。ジャスト倍率は命中には掛けない(初撃だけ:5.7)。会心率は 表 + 連撃・心 × 段数 + 勢い + 先制 + 芯 に逓減をかけたもの。貫通は 表 + 連撃・貫 × 段数 に逓減をかけたもの。会心率が 100% をこえると追加クリティカル(5.9)。クリティカルの乱数は命中 1 回につき 1 回。
- 先手・勢いは「戦闘中の一時的な上乗せ」に積み、次の命中で消える。止めても保持され、保存はしない。
- ミスをはさむ遊び方(直前にミス、満タンに戻す)は、ふつうに命中させるより速くならない(重いテストで確かめる)。先制は、満タンに戻すと 1〜2% 得になったので、最初の命中までに狭めた(D-192)。

### 5.17 降臨(レイド風:D-396・D-397・D-403)

- 何をするか:4 キャラ(疾風の大エビ・鉄壁の大ガニ・不死の大ダコ・刹那の大イカ。名前は D-402)に、挑戦ごとのダメージを積み重ねて挑む。倒すまで何回でも無料で挑める。目次の「降臨」の画面で、ウロコパワーを注入して呼び、挑む。港を越えたら(磯に入ったら)遊べる(港では「港を越えると…」とだけ出す)。
- キャラとお守り(1 対 1):

| キャラ | くせ | 倒すと授かるお守り | お守りの効果(上限) | 効く戦い |
| --- | --- | --- | --- | --- |
| 疾風の大エビ | 速い印(× 0.66) | 静めの守り | 印の速さ −40% | どの戦いにも |
| 鉄壁の大ガニ | 防御の壁(ふつうの貫通 + 20%。下限なし) | 破りの守り | ダメージ +50% | ヌシ戦と降臨 |
| 不死の大ダコ | 自動回復(1 秒に体力の 1%) | 和らぎの守り | くせ −60% | ヌシ戦と降臨 |
| 刹那の大イカ | 短い制限時間(× 0.5) | 刻の守り | 制限時間 +60% | ヌシ戦と降臨 |

- 強さ:キャラごとにレベル 1 から。レベル n を倒すと、次はレベル n + 1(上限なし)。レベル n の体力 = 段階 n のヌシの体力(キャラのくせの補正つき)× 6(疾風の大エビだけ × 5:D-404)を上から 2 けた。印の速さ・命中範囲の幅・制限時間は段階 n のヌシと同じで、くせはキャラのもの。
- ウロコパワー(D-403):釣り上げで貯まる(4 体で共通。上限なし)。弱い魚 1・強い魚とヌシ 5(餌の強い魚は 1)に、魚の段階ごとの補正 2^(段階 − 1) を掛ける。竿の段階には依らない。
- 注入:4 体それぞれに「注入する」。レベル L の相手に要る量は 240 × 2^(L − 1)。注入すると、まず強い魚の鱗の余り(前の段階は全部、今の段階は製作に要る分を残す。ヌシの鱗は入れない)を 1 枚の量が多い順に入れ(1 枚 10 × 2^(鱗の段階 − 1)。鱗で入れられるのは要る量の半分まで。最後の 1 枚はこえる分を切り捨て)、残りを貯めたウロコパワーで埋める(要る量まで)。注入した量は相手ごとに残る。相手のレベルより低い段階の魚・鱗ほど少なくしか貯まらない(1 段階低いと半分)。
- 呼ぶ:要る量まで注入した相手を呼ぶ(注入した分は使い切る)。呼べるのは 1 度に 1 体。
- 挑む:どの釣り場でも、投げる・待つの間に挑める。待っていた魚は取っておき、戦いのあとに続きから。体力は残りから始まり、最大は降臨の体力(ミスと自動回復で戻るのは最大まで)。時間切れなら、残りの体力が残る(再読み込みしても残る)。戦いと結果の間だけ、いまいる釣り場の背景が夜になり、キャラは画面の幅いっぱい(64 × 64 マス、1 マス = 画面の幅 ÷ 64)。
- 区切りの報酬:削った量の 10% ごと(挑戦の終わりの残りの体力で数える。同じレベルの同じ区切りは 1 回)。10・30・70・90% はウロコイン(そのレベルの強い魚 5 匹ぶん)、20・40・60・80% は段階 min(レベル, 竿の段階) のクレートを 1 回ただで(引いた回数が進む。自動分解の設定に従う。持ち物がいっぱいならクレートの価格のウロコイン)、50% はグローブの抽選 1 回(グレードは竿の段階。保管がいっぱいなら強い魚 5 匹ぶんのウロコイン)、100%(討伐)はお守り。結果の場面では、討伐は「討伐!」の帯と光と粒。報酬の中身は、挑戦の終わりのシート(報酬の一覧)に出す(浮かぶ文字にはしない:D-404)。
- お守り:討伐でそのキャラのお守りを授かる(初めては新しく、2 回目からはレベルが上がる。レベル n を倒すとレベル n)。効果 = 上限 × L ÷(L + 15)。付けている 1 つだけが効く(降臨の画面の「付ける・外す」。初めて授かったとき、何も付けていなければ自動で付ける)。静め:印を遅くする割合に足す(基準の 50% より遅くしない)。刻:制限時間 ×(1 + 効果)(糸・粘りの延長の上限の外)。破り:1 命中・かすりのダメージ ×(1 + 効果)。和らぎ:くせの数(命中範囲・防御・印の速さ・回復・制限時間)を、くせなしの値へ効果の割合だけ近づける(体力はそのまま)。
- 報酬の一覧(D-402):挑戦が終わると、討伐の演出のあと(1.2 秒)、下から出るシートで「もらった報酬」を出す。見出し(討伐!/挑戦)・ダメージと残り・報酬ごとの行(種類の札・クレートは★と色つきの装備名・自動分解なら戻ったウロコイン・グローブはグレード・いっぱいでウロコインに替わったらその一言)。報酬がなければ「次の報酬まで あと n%」。OK か外側のタップで閉じる。出ている間は釣りを止める。
- 乱数:降臨の塩・キャラ・レベル・挑戦の回数から作る別の系統。魚の系統は使わない(同じシードなら同じ結果)。
- 目安(重いテスト):段階 g の目安の装備(キャラのくせに合わせて付け替え)と、ふつうの遊び方で、レベル g を倒すまでの挑戦は 3〜7 回(大エビ 5〜7・大ガニ 3〜5・大ダコ 3〜5・大イカ 4〜6)。ウロコパワーは上手に釣り続けて、シミュレーションの 1 時間で、竿と同じレベルの相手に要る量の 1.8〜2.6 回分(段階 6・8・10・13。実際の遊びで約 1 時間に 1 回呼べる)。
- デバッグ(?debug):「降臨」の節で、全員に要る量まで注入する・残りの体力を決める・お守りのレベルを決める。

### 5.18 魚の図鑑と大きさ(D-405)

- 釣れた魚(弱い魚・強い魚・ヌシ。降臨は数えない)ごとに大きさが決まる。大きさ = 魚の標準の大きさ(cm。魚の表の `cm`)× 倍率(0.80〜1.25)。小数 1 けた。
- 倍率は、0〜1 の数 u から区分けの直線で作る:u が 1% 未満 → 0.80〜0.85、94% → 0.851〜1.119、4% → 1.12〜1.199、1% → 1.20〜1.25。
- 冠(モンハンの王冠と同じ考え):金冠 = 倍率 1.20 以上(約 1%)、銀冠 = 1.12 以上(約 5%。金冠を含む)、ミニ金冠 = 0.85 以下(約 1%)。
- 乱数:魚の系統は使わない。シードと「その魚を釣った数」から作る(同じシード・同じ回数目なら同じ大きさ。魚の出方は変わらない)。
- 図鑑:魚ごとに、釣った数・最小と最大の大きさ・取った冠を記録する。目次の「図鑑」で、釣り場ごとに見られる(いちばん新しい釣り場だけ開く)。1 行は名前と冠の印(〔金〕金冠・〔銀〕銀冠・〔小〕ミニ金冠)と釣った数。押すと、釣れる場所・標準の大きさ・釣った大きさ(最小〜最大)・冠 3 つ(取ったか)。まだ釣っていない魚は「???」。図鑑ができる前に釣った魚は「記録なし」(これから釣ると記録される)。上に「登録 n / 90 種類・冠 m / 270」。
- 演出:釣れると魚の下に「22.7cm」(冠つきの個体は「金冠 49.4cm」、最大・最小を更新したら「・最大!」「・最小!」)。新しく冠を取ったら、その冠の帯(「金冠!」など)と金の粒。初めての魚なら「はじめて!・金冠!」。
- これから:図鑑と紐づく永久バフ(魚ごとの節目。ダメージ・会心率・防御を下げる)と、観賞用の水槽(最大・最小・普通の大きさから選んで飾る)。

- 画面が裏に回るなどで描画の間隔が空いても、1 回に進める時間は 0.1 秒までにする(一気に何匹も進まない)。
- ミニゲーム以外のタップは何もしない。
- 保存データが壊れている・形がちがう・版がちがうときは、エラーにせず初めの状態から始める(D-065)。表にない魚の id・存在しない工程・範囲外の数・重複・持ち物にない装着の番号を含むデータは拒否する(D-232)。
- セーブコードが空・古い版(FISH)・形がちがう・壊れている(印が合わない)・版がちがう・数が範囲外・表にない魚や工程・重複・持ち物にない装着・署名が合わない・知らない鍵・(本番で)デバッグ用・(acceptUnsigned が false のとき)署名なし、のときは、短いエラーを出し、いまの保存データは一切変えない。読み込みの前に「上書きしますか?」を確かめる(D-065・D-092)。
- ブラウザの設定で保存が使えないときも、保存せずに遊べる。

## 7. 用語集

| 用語 | 説明 |
| --- | --- |
| 命中 | 体力制の戦いで、命中範囲の中でタップして、魚にダメージが入ること(D-180)。 |
| ミス | 命中範囲の外でタップして、魚の体力が回復すること(D-180)。 |
| 命中範囲 | ゲージの中の、タップするとダメージが入る範囲(前の「当たり範囲」)。 |
| 合わせ | 魚が掛かったときの、輪のタップ。結果は「成功・ジャスト・失敗」。「命中」とは言わない。 |
| 高レア・低レア | ガチャのレア度の高さ。「当たり外れ」とは言わない。 |
| 芯 | 命中範囲の真ん中の帯。ここで命中すると、ゲージ系スキル「芯」で会心率が上がる(D-197)。 |
| 縁 | 命中範囲の端のぎりぎりの帯。ここで命中すると、ゲージ系スキル「縁」でダメージが上がる(D-197)。 |
| 連撃 | 続けて命中した回数(段数)。ミスでリセット、戦いが終わると消える(D-185)。 |
| 条件発動型 | 戦いの流れ(連撃・合わせの結果・体力の残りなど)の条件を満たしたときだけ効くスキル(D-184)。 |
| 計算本体 | `src/core/` にある、画面に関係しないゲームの決まりと乱数(D-028)。 |
| クリッカー | 放置やタップのくり返しで数が増えていくゲーム。 |
| ハクスラ | 拾った(引いた)装備を組み合わせて強くなるゲーム。 |
| ウロコイン | ゲーム内のお金。クレートガチャに使う(D-032)。 |
| 鱗 | 強い魚とヌシから 1 枚ずつ取れる、魚ごとの素材。竿の製作と進化に使う(D-097)。 |
| ヌシ | 段階ごとの大物。自分で挑む体力制の戦い(D-094)。 |
| 竿の段階と工程 | 進行度。製作 → ヌシ撃破 → 進化で次の段階へ進み、新しい魚が釣れる(D-098)。 |
| クレート | 装備が出る箱。ウロコインで引くガチャ(D-122)。 |
| レア度 | 装備の珍しさ。ノーマル・レア・エピック・レジェンドの 4 段階。高いほど基本効果が大きい(D-147)。 |
| グレード | 装備の基本効果の大きさの目安。引いたクレートの段階と同じ(D-147)。 |
| 分解 | 装備を手放して、ウロコインを少し受け取ること(D-137)。 |
| 合わせ | 魚が掛かった瞬間のタップ。縮む輪が成功帯にあるうちに押す(D-082)。 |
| 体力(HP) | 強い魚の粘り強さ。ミニゲームの命中で減り、ゼロで釣り上げ(D-056)。 |
| セーブコード | 進み具合を 1 行の文字列にしたもの。別のブラウザに持ち出せる(D-059)。 |
| 署名 | セーブコードの最後に付ける、鍵(合言葉の文字列)から計算した印。鍵を知らないと正しく作れないので、書き換えると合わなくなる(HMAC-SHA256:D-291)。 |
| Secrets | GitHub に置く秘密の値の保管場所。公開の処理だけが読め、記録には出ない(D-292)。 |

| ジャスト | 成功帯の真ん中で合わせた最高評価(D-082)。 |
