# 仕様(SPEC)

このプロジェクトが「何をするか」を書く文書です。「どう作るか」は [DESIGN.md](DESIGN.md) に書きます。

## 書式の見本

```
## 章の名前

- 決まっていること(関係する D 番号があれば書く)
- 未定のこと:……(DESIGN の「検討中の論点」へ)
```

---

## 1. 目的と範囲

- 目的:スマホのブラウザで動く、釣り×クリッカー(放置でも進むゲーム)×ローグライク/ハクスラ(ランごとに変わる装備で強くなるゲーム)のゲームを作る(D-016)。
- 目標の姿:「自動で釣れる気持ちよさと、強い魚とのミニゲーム、ランごとに変わる装備の組み合わせで強くなっていく釣りゲーム」。迷ったときは、これに近づくほうを選ぶ(D-017)。
- 進み方:普通の魚は自動で釣れ続ける。強い魚が掛かったらミニゲーム。強い魚ほど重いミニゲームにする(D-018)。
- ランの終わり方:1 ランは数分の時間制。時間が尽きたら終わり、持ち帰った素材で強化する(D-019)。
- 経済の流れ:魚を釣ると「素材」と「ウロコイン」(ゲーム内のお金)が手に入る。素材は竿の強化、ウロコインはクレートガチャ(②-2)に使う(D-032)。
- 竿は進行度の軸。段階が上がると新しい魚が釣れるようになる。待ち時間や強い魚の出やすさは竿では変えない(D-033)。竿は素材で確実に強くなり、装備はガチャで運の要素がある(D-041)。
- 作る順番:①釣りの 1 サイクル → ②-1 魚の種類と報酬、竿の強化 → ②-2 クレートガチャ・装備枠 → ③強化の拡張 → ④ローグライク・ハクスラ要素(時間制のランも)(D-040)。
- 今あるもの:①釣りの 1 サイクル、②-1 魚の種類と報酬・竿の強化・保存・手応えの演出(この文書の 5 章)。
- まだないもの:クレートガチャ、装備、時間制のラン、ローグライク・ハクスラ要素、魚の図鑑、音、2 つ目以降のミニゲーム、複数の釣り場。

### 1.1 これから作るもの(決まっていること)

- 装備の種類:糸・おもり・リール・浮き・ルアー・おまもり。通常のクレートから出る。釣れるクレートは出現率が低く、グローブ(特殊な装備枠)だけが出る(D-038)。
- クレートは現実のお金を使わず、排出率を画面に出す(D-039)。
- 新しい釣り場やボスの解放条件も、竿の段階にそろえる方針(D-037)。

## 2. 使う人と使い方

- 縦持ちのスマホで、ブラウザから遊ぶ(D-020)。
- 操作はタップだけ。放置していても、普通の魚は釣れ続ける。
- 公開の URL(GitHub Pages)をスマホで開けば、PC の準備なしに遊べる(D-043)。

## 3. 入力

- タップ(釣りの絵のどこでも)。ミニゲームの間だけ意味がある。
- 竿の強化のボタン(画面の下)。素材が足りないときは押せない。
- 「データを消す」(画面の左下の小さな文字)。2 回続けて押したときだけ消える。
- URL の `?seed=数` で、乱数のシードを固定できる(D-021・D-030)。付けないときは毎回ちがうシードになり、画面の左下に表示される。

## 4. 出力

- 画面は上・真ん中・下の 3 段(D-051)。
  - 上:ウロコインと素材の数。
  - 真ん中:釣りの絵と、今の場面の文(「待っています…」「掛かった!」「強い魚だ!」、結果は「アジが釣れた」「クロダイを釣り上げた!」「クロダイに逃げられた…」のように魚の名前つき)。
  - 下:竿の強化のボタン(「竿 段階1→2 | 素材 10 | 新しい魚が釣れる」)、「データを消す」、シード。
- 絵:空・水面・竿・糸・浮き・魚、ミニゲームのゲージ。画像素材は使わず、図形で描く。魚は種類ごとに色と大きさがちがう。
- 手応えの演出(D-042・D-051):釣れたら緑に光り「+n ウロコイン」「+n 素材」が浮かぶ。逃げられたら赤く光って揺れる。初めて釣れた魚は金色に光り「はじめて!」の帯が出る。竿を強化すると「竿が段階 n に!」が出る。
- 保存:ウロコイン・素材・竿の段階・一度でも釣れた魚を、ブラウザの中に保存する。再読み込みしても続きから遊べる(D-050)。

## 5. 計算の中身

### 5.1 釣りの 1 サイクル

場面は次の順にくり返す。

1. 投げる(0.7 秒)
2. 待つ(1.5〜7.5 秒の一様な乱数。平均 4.5 秒)
3. 掛かる(0.5 秒)。このとき魚の種類が分かる。強い魚は全部の段階で 20%(D-029・D-033)。
4. 普通の魚:自動で巻き上げる(0.9 秒)→ 釣れる。
   強い魚:ミニゲーム(5.2)。
5. 結果を見せる(1.2 秒)。釣れたら、その魚の報酬(ウロコインと素材)が増える。逃げられたら何も増えない。→ 1 へ。

### 5.2 ミニゲーム(タイミング)

- 横長のゲージの上を、印が端から端まで往復する。速さは強い魚ごとにちがう(5.4)。
- ゲージの一部が当たり範囲。幅は強い魚ごとにちがい、位置は乱数で決め、ゲージの端から 8% 以上はなす。
- 当たり範囲の中でタップすれば成功(釣れる)、外なら失敗(逃げられる)。境界ちょうどは成功。
- 5 秒タップしなければ逃げられる。
- 限界:当たり範囲の幅はゲージの 10% より狭くしない。印は端から端まで 0.45 秒より速くしない(D-036・D-048)。

### 5.3 乱数

- 1 回の投げごとに、待ち時間 → 魚 → (強い魚なら)当たり範囲の順に乱数を引く。
- 魚の乱数 1 回で、区分(普通/強い)と種類をまとめて決める(D-046)。段階 1 の並びは Issue #4 のときと同じ。
- 同じシードで同じ操作(タップと強化)をすれば、ウロコイン・素材・竿の段階・釣果の並びは完全に同じになる(D-021)。
- 数値は `src/core/config.js`、魚の設定表は `src/core/fish.js` にある。

### 5.4 魚の一覧(D-045)

| 段階 | 普通の魚(ウロコイン/素材) | 強い魚(ウロコイン/素材、印が端から端まで、当たり範囲) |
| --- | --- | --- |
| 1 | アジ(1/1) | クロダイ(5/3、0.9 秒、22%) |
| 2 | サバ(3/2) | スズキ(15/6、0.8 秒、19%) |
| 3 | カワハギ(8/4) | ブリ(40/12、0.7 秒、16%) |
| 4 | タチウオ(20/8) | カツオ(100/24、0.6 秒、13%) |
| 5 | ヒラメ(50/16) | マグロ(250/48、0.52 秒、11%) |

- 竿の段階 n では、段階 n 以下の魚だけが釣れる(D-035)。
- 区分の中では、新しい段階の魚ほど出やすい。重みは段階ごとに 2 倍(段階 3 なら 1:2:4)(D-046)。

### 5.5 竿の強化(D-047)

- 竿の段階は 1〜5。最初は 1。
- 素材を使って 1 つ上げる。必要な素材:1→2 が 10、2→3 が 30、3→4 が 80、4→5 が 200。ウロコインは使わない。
- 素材が足りないと強化できない。足りれば、必要な数だけ減る。
- 効果は「新しい魚が釣れる魚の一覧に加わる」だけ。新しい魚は、強化したあと次に投げるときから出る。

## 6. 間違いや例外の扱い

- 画面が裏に回るなどで描画の間隔が空いても、1 回に進める時間は 0.1 秒までにする(一気に何匹も進まない)。
- ミニゲーム以外のタップは何もしない。
- 保存データが壊れている・形がちがう・版がちがうときは、エラーにせず初めの状態から始める(D-050)。
- ブラウザの設定で保存が使えないときも、保存せずに遊べる。

## 7. 用語集

| 用語 | 説明 |
| --- | --- |
| 計算本体 | `src/core/` にある、画面に関係しないゲームの決まりと乱数(D-028)。 |
| クリッカー | 放置やタップのくり返しで数が増えていくゲーム。 |
| ローグライク/ハクスラ | 1 回ごとに中身が変わる挑戦(ラン)で、拾った装備を組み合わせて強くなるゲーム。 |
| ラン | 1 回の挑戦。時間制(D-019)。 |
| ウロコイン | ゲーム内のお金。クレートガチャに使う(D-032)。 |
| 素材 | 竿の強化に使う(D-032・D-049)。 |
| 竿の段階 | 進行度。上がると新しい魚が釣れる(D-033)。 |
| クレート | 装備が出る箱。ウロコインで引くガチャ(②-2)。 |
| シード | 乱数の出発点になる数。同じなら同じ乱数が出る。 |
| 当たり範囲 | ミニゲームで、タップすれば成功になるゲージの部分。 |
