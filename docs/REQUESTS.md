# 要望の控え(REQUESTS)

オーナーの要望を、まだ依頼にしていないものも含めて控えておく文書です。

## 書式の見本

```
- 要望の要点(出どころ:報告 `#2` など/関係する依頼名)
```

---

## 対応済み

- プロジェクトの目的を決める(出どころ:報告 #2/「言語の切り替えと、釣りの1サイクル」の【0】で決定、D-016)。
- main の保護の設定をどうするか(出どころ:報告 #2/オーナーが行うと決定、D-024)。

## 候補

- スマホで外から開けるようにする(GitHub Pages など)。公開の設定はオーナーが決める(DESIGN の「検討中の論点」)。

## 時期の決まったもの

- 素材(②)、強化・時間制のラン(③)、ローグライク・ハクスラ要素(④)。順番は D-023。
- 2 つ目以降のミニゲーム、強い魚ほど重いミニゲーム(D-018)。
- セーブ(保存)、音、複数の釣り場、画像素材:時期は未定。
