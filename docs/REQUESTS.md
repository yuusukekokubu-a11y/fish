# 要望の控え(REQUESTS)

オーナーの要望を、まだ依頼にしていないものも含めて控えておく文書です。

## 書式の見本

```
- 要望の要点(出どころ:報告 `#2` など/関係する依頼名)
```

---

## 対応済み

- プロジェクトの目的を決める(出どころ:報告 #2/「言語の切り替えと、釣りの1サイクル」の【0】で決定、D-016)。
- main の保護の設定をどうするか(出どころ:報告 #2/オーナーが行うと決定、D-024)。
- スマホで外から開けるようにする(出どころ:報告 #4/GitHub Pages で公開、D-043)。
- 強い魚ほど重いミニゲーム(D-018/②-1 で魚ごとの印の速さと当たり範囲として対応、D-048)。
- 手応えの演出(出どころ:報告 #4/D-042・D-051)。
- セーブ(保存)(②-1 で対応、D-050)。
- 報告 Issue は取り込みのあとに発行する(出どころ:報告 #4 のあとの会話/D-031)。
- 放置で進まないタップ主体の手触り:合わせと体力制(出どころ:報告 #6 のあとの依頼/②-2 で対応、D-053〜D-056)。
- 記録をブラウザの外に持ち出す(②-2 でセーブコードとして対応、D-059)。
- 戦闘の数値化:体力のバー、ダメージの数字、クリティカル(出どころ:報告 #8 のあとの依頼/②-3 で対応、D-068〜D-071)。

## 候補

- 魚の図鑑(一度でも釣れた魚の記録 `seen` は保存してある)。
- 素材を魚ごとに分ける(D-049 で 1 種類から始めた)。
- クラウド保存・アカウント(②-2 では作らない、D-059)。
- 腕前型のクリティカル(当たり範囲の中心の帯)をレア装備の能力に(D-070)。
- 特性のルール変更型(当たり範囲が増える など)(D-073)。
- 魚の側の性質(弱点・暴れ方)と装備の相性(D-075)。
- ダメージの種類(属性など)。

## 時期の決まったもの

- クレートガチャ・装備枠と糸・リール・ルアー、レア度・特性(②-4)、おもり・浮き・おまもり・グローブ・釣れるクレート(②-5)、強化の拡張(③)、ローグライク・ハクスラ要素と時間制のラン(④)。順番は D-076。
- 新しい釣り場・ボス(解放条件は竿の段階にそろえる、D-037):時期は未定。
- 2 つ目以降のミニゲーム、音、画像素材:時期は未定。
