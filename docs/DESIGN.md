### ファイルの大きさの目安

- 1 つのファイルは 800 行以内を目安にする。超えるなら分ける(D-006)。
- 分けない場合は、下の「800 行を超えるファイル」にファイル名と理由を書く。`tests/test_file_size.py` が、ここに載っていない 800 行超えのファイルを見つけると失敗する。

## GitHub のテストの流れ

設定は `.github/workflows/ci.yml` の 1 つです。

| いつ | 回るもの |
| --- | --- |
| PR を出した・更新したとき | 速いテスト。計算本体が変わったときだけ重いテストも(D-005・D-012)。 |
| main に取り込んだあと | 速いテストだけ(版は 1 つ)。 |
| 手動(Actions の画面の「Run workflow」) | 重いテスト。 |

- 同じ PR を出し直したときは、古い実行を止める(concurrency:同時に走る実行のまとめ役の設定)。
- 最後の `ci-result` ジョブが、ほかの結果をまとめる(D-015)。
- 速いテストは今は 1 つのジョブで回している。5 分を超えるようになったら、テストを分けて同時に走らせる。
