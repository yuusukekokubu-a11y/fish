# 決定の記録(DECISIONS)

このプロジェクトで決めたことを、決めた順に D 番号つきで残します。
一度書いた決定は消しません。変えるときは新しい D 番号を足し、「置き換えた番号」に古い番号を書きます。
今も有効な決定だけの一覧は [ACTIVE_DECISIONS.md](ACTIVE_DECISIONS.md) にあります。決定を足す・変えるたびに、一覧も直します。
このファイルには D-167 以降の今有効な決定を書きます。D-001〜D-092 は [decisions/vol1.md](decisions/vol1.md)(第 1 巻)、D-093〜D-130 は [decisions/vol2.md](decisions/vol2.md)(第 2 巻)、D-132〜D-164 は [decisions/vol3.md](decisions/vol3.md)(第 3 巻)にあります(D-133)。
置き換えられた決定・取り下げた決定・完了した一度きりの段取りは、元の文のまま [decisions/archive.md](decisions/archive.md) に移してあります(D-110)。D 番号の通し番号は、これらのファイルを合わせて数えます。
このファイルが 700 行をこえたら、古いほうの番号をまとめて次の巻(`decisions/vol4.md` など)へ移します(D-133)。

## 書式の見本

```
## D-XXX 決定の短い題名

- 日付:YYYY-MM-DD
- 決定:何を決めたか。
- 理由:なぜそう決めたか。
- 置き換えた番号:なし(または D-YYY)
```

- D 番号は 3 けたの通し番号です。飛ばしたり、使い回したりしません。
- 「置き換えた番号」に書かれた古い決定は、節ごと `docs/decisions/archive.md` に移し、そこの一覧に 1 行足します。ACTIVE_DECISIONS からは消します。

## D-169 会心率の追加クリティカルと、戦闘の数値の限界

- 日付:2026-10-05
- 決定:
  - 会心率 c(%)を 100 で割った商は、必ず起きるクリティカルの段数。余りは、もう 1 段増える確率。
  - ダメージ = 通常ダメージ ×(倍率の段数乗)。その他の倍率は、これまでの順どおり。
  - 当たりのたびに、クリティカルの系統から乱数を 1 回だけ引く。会心率が 100% 以下のときは、これまでと完全に同じ結果になる。

    - 体力:クロダイ 20 〜 マグロ 60。制限時間 8〜12 秒。
    - 基本の表:通常ダメージ 10、クリティカルの確率 10%、倍率 2 倍、外したときの回復 10、制限時間の増減 0 秒。
    - 範囲外の値は境目に直し、数でない値は基本の値に戻す。ダメージ・回復は四捨五入した整数、ダメージ 1 以上、回復 0 以上、制限時間 1 秒以上。
- 理由:依頼の【0】による。

## D-181 ルアーの基本効果は「命中範囲の広さ」(割合型)

- 日付:2026-10-06
- 決定:
  - ルアーの基本効果は、魚の命中範囲の幅に対して +n%(幅 ×(1 + n))。魚が強くなって範囲が狭くなっても、同じ割合で助ける。レア度とグレードが高いほど n が大きい。強い魚とヌシの戦いに効く。
  - 上限は、ゲージ全体の一定割合(目安 70%)。下限(画面の 10% 以上)は変えない。
  - D-176(ミスのあとの上乗せ。ルアーの外し得対策)は廃止する。戦闘の数値の表の「外したあとの次の当たり」(`missBonusDamage`)もなくす。ミスのときは回復だけが起きる。
  - ほかの装備は前のまま:糸 = 制限時間(`timeLimitBonusMs`)、リール = 通常ダメージ(`damage`)に足し算。安全上限だけを置く。装着・外す・分解は、戦いの最中(メニューで止めている間)でもでき、ダメージは次の命中から、制限時間と命中範囲は次の戦いから変わる。
  - ミスをはさむ遊び方が、ミスをしない遊び方より得にならないこと(外し得なし)は、引き続き重いテストで確かめる。
- 理由:依頼の【0】による。高レアのルアーが無駄にならず、画面で効きが見えるように。
- 置き換えた番号:D-127・D-145・D-170・D-176

## D-191 条件発動型の効果の大きさと、命中 1 回の計算の順

## D-193 ルアーの数値と、命中範囲の広げ方

- 日付:2026-10-06
- 決定:

## D-195 スキルは完全にレベル制(ポイントをなくす)

- 日付:2026-10-06
- 決定:
  - 装備のスキルは整数のレベルを持つ(例:会心率 Lv2)。装着中の装備の同じスキルのレベルを足したものが、そのスキルのレベル。最大レベルはこれまでどおり(成長型は 2 + 竿の段階、頭打ち型は 3)。最大をこえた分は無駄になる。
