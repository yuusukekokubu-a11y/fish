## D-065 保存の版 2 とセーブコードの形式

- 日付:2026-10-05
- 決定:保存の形を版 2 にする:`{ "version": 2, "progress": { "coins", "material", "rodStage", "seen" } }`。②-3 の装備は、`progress` と並べて足す。版 1(`{ version: 1, coins, material, rodStage, seen }`)は読み込むときに版 2 に読み替える。セーブコードは `FISH2-(中身)-(印)` の形の 1 行の文字列。中身は保存の形の JSON を base64url(英数字と「-」「_」だけで文字を表す書き方)にしたもの、印は中身から計算する 8 けたの 16 進数(FNV-1a という計算のチェックサム:中身が 1 文字でも変わると値が変わる)。読み込みでは、形・印・版・数の範囲を全部確かめ、1 つでもおかしければ短いエラーを出して、いまの保存データを一切変えない。暗号化はしない。
- 理由:実装中に決めた細部(D-004)。目的は壊れたデータの検出で、改ざんの防止ではないため、短くて計算が軽い印にした。先頭の `FISH2` で、ほかの文字列とまちがえて貼り付けたときもすぐ分かる。
