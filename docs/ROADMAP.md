# 依頼の予定(ROADMAP)

依頼の予定を、完了・作業中・これからに分けて書きます。依頼は 1 つずつ進めます(D-001)。
作る順番は D-023 のとおりです。

## 書式の見本

```
- 依頼名:一言の説明(PR や報告 Issue の番号。例:PR `#1`、報告 `#2`)
```

---

## 完了

- 初期の環境づくり(開発の流れの土台):文書・手順書・ひな形・テストの設定(PR #1、報告 #2)。

## 作業中

- 言語の切り替えと、釣りの1サイクル(タイミングのミニゲーム込み):JavaScript への切り替えと、①釣りの 1 サイクル。

## これから

1. ②釣ったものと素材:釣った魚から素材が手に入る。
2. ③強化:持ち帰った素材で強化する。時間制のラン(D-019)もこのあたりで入れる。
3. ④ローグライク・ハクスラ要素:ランごとに変わる装備の組み合わせ。
